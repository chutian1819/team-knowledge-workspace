## 给同事使用

交付时入口：<https://1a9310c09c4af2.lhr.life>。这是临时地址；转发前双击项目目录中的 **查看公网地址.command** 获取当前地址。服务商在本轮工作中已轮换过一次地址，运行程序成功记录新地址；下方公网验收使用轮换前的 `https://8ba9ab8258469c.lhr.life`，新地址的 HTTPS 登录配置接口也已复核成功。

1. 在这台 Mac 双击 **开通同事账号.command**，输入同事姓名与登录邮箱。脚本通过本机接口创建独立账号和个人空间，生成随机密码；只在终端显示，不会发送邮件或重置同名旧账号。由你私下把登录信息交给对应同事。
2. 同事通过当前 HTTPS 地址登录。每人使用自己的账号；在“共享空间”加入项目组织，再到“研究工作台 → 团队项目”查看授权资料。
3. 资料所有者选择文件并共享到项目，核对实际成员名单。文件仍保持同一个知识 ID，后续替换原件不需要再次分发副本。

5. 只读成员可预览原件、读取正文及版本记录；替换原件、直接下载原件及批量 ZIP 需要相应编辑权限。下载后的离线副本无法随撤权收回。

公网入口限制了自由注册，已有账号可以正常登录。本机 `http://localhost:8090` 仍可管理账号。原有 `FRONTEND_BASE_URL=http://localhost:8090` 已置空，使邀请链接由浏览器当前地址生成；原配置保留在忽略目录 `.research-private/public-trial/env-before`。项目组织与 Workspace 成员是不同概念：研究工作台的个人收件箱要求一人一个 Workspace，请优先使用上面的独立账号方式。

## 启动、关闭与可用性

| 操作 | 项目目录中的入口 |
| --- | --- |
| 开启公网访问 | `启动公网试用.command` |
| 查看最新地址 | `查看公网地址.command` |
| 关闭公网访问，保留本机服务和文件 | `停止公网试用.command` |
| 给同事创建独立账号 | `开通同事账号.command` |

平台及 Docker/Colima 必须运行。公网隧道已安装为当前 macOS 用户的 LaunchAgent，在用户登录时启动，连接失败后由 launchd 重启。运行时使用 `caffeinate -i` 防止空闲休眠；关机、断网、退出登录、手动睡眠或合盖仍可能导致不可用。没有更改系统全局休眠设置。

LaunchAgent：`~/Library/LaunchAgents/local.research.public-trial.plist`。状态、当前地址、SSH 主机密钥记录和运行脚本位于 `~/Library/Application Support/ResearchPublicTrial/`。隧道仅连接回环地址 `127.0.0.1:8091`；网关转发到原平台前端，没有向公网暴露 PostgreSQL、Redis、模型或 Langfuse 端口。

localhost.run 免费域名会定期变化并受速度限制，没有固定地址或可用性承诺；适合本轮小范围试用。固定域名和持续服务需要后续配置正式隧道或公网网络入口。参见服务商的[免费方案说明](https://localhost.run/docs/forever-free/)和[连接与重连说明](https://localhost.run/docs/faq/)。请始终分享 HTTPS 链接。
