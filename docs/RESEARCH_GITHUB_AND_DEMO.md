# 源码发布与演示资料维护

GitHub 仓库：<https://github.com/chutian1819/team-knowledge-workspace>，公开源码。

本项目基于 Tencent WeKnora v0.8.3 扩展。保留上游许可证、第三方声明和原始说明；定制功能与部署入口以根目录 `RESEARCH.md` 为准。

## 仓库包含什么

仓库包含应用源码、前后端依赖锁文件、数据库迁移、Docker 部署配置、运维脚本、回归测试和演示导览。首个公开提交为当前完整源码快照；此前本地开发历史保留在原开发分支。

`.env`、`.research-*`、账号与会话凭据、数据库导出、上传原件、模型缓存、备份和本地验收产物不进入仓库。实际部署使用自己的配置、模型服务和数据。

## 当前演示库

2026-10-23，本机运行实例从 44 个知识库整理为一个“演示知识库 · 具身智能研究”，保留管理员个人收件箱的原有身份，研究工作台继续使用该库收集资料。

演示内容按“论文资料 / 网页资料 / 图片资料”归档，包括 π0 原始论文、官方介绍、DigitalBuddy 官方报道、公众号原文、HTML 存档和原图，并提供一份演示导览。保留原知识 ID、原件和来源历史，不重新抓取网页。

其余 43 个验收、压测、临时共享及研究稿库通过原生删除接口移除，连带清理对应文档、分块、索引和 Wiki。保留库中的旧合成草稿也已移除。此次整理不重置用户账号或模型配置。

源代码仓库只提供[演示导览](../examples/research-demo/演示导览.md)，不附带运行数据库、已登录会话或第三方资料原件。新部署可按导览导入合法取得的演示资料。

## 备份与日常维护

清理前已保存并校验数据库、原件和 Redis 队列的一致性备份。备份仅留本机 `.research-backups/before-demo-cleanup-20261023/`，包含敏感配置，不应上传或公开分享。

这次备份重启暴露出 Redis 增量 AOF 的两处损坏。原始日志另存于本机私有目录；恢复时保留全部可解析的完整命令，仅移除损坏片段，恢复后的 AOF 和清单通过 Redis 检查工具验证。清理前备份中的 Redis 归档仍是原始损坏版本；若要恢复该备份，应同时使用本机保留的修复日志，或使用清理后通过重启验证的新备份。

后续请在隔离实例运行验收及容量测试。现有验收脚本会创建合成账号、知识库和研究稿，再次在演示实例运行会重新产生测试数据。正式资料应存放到新建资料集；实际使用需要新增收件箱或研究稿库时，知识库数量自然增加。

查看运行状态与创建新备份：

```sh
python3 scripts/researchctl.py status
python3 scripts/researchctl.py backup /绝对路径/新备份目录
python3 scripts/researchctl.py verify-backup /绝对路径/备份目录
```

备份和恢复流程、适用范围见 [RESEARCH.md](../RESEARCH.md)。
