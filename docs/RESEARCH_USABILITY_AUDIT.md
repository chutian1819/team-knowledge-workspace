## 五步法应用

1. **质疑需求**：收件箱负责临时收集；我的资料负责按主题整理；团队项目负责共享访问。必须对应不同的数据范围，不能只是切换高亮。研究工作台和知识库保留两个入口，前者串联收集与写作，后者承载原文、分块、检索、数据源及高级设置。
2. **删除冗余**：收件箱删除可切到任意资料集的下拉；我的资料排除收件箱、研究稿专用库和 FAQ；团队资料集按知识库 ID 去重；收件箱不再重复放“新建资料集”。兼容 URL 继续重定向到唯一设置/工具页面，没有复制第二份设置页面。
3. **简化**：三个分区各自说明用途、显示正确空状态；回到我的资料记住上次选择；“个人偏好”改称实际目的地“个人记忆”，与研究稿中的“写作经验”区分。所有者、贡献者和只读成员看到与权限相符的创建/管理入口。
4. **提速**：已存在的后台导入、共享和归档继续异步处理；页面隐藏时暂停资料轮询，终态任务停止轮询；切换库丢弃旧响应，避免慢请求把上一分区内容覆盖回来。本轮没有声称服务器吞吐或模型时延提升。
5. **自动化**：新增真实组件导航回归、数据分区测试和全量交互清单生成器；写作过程继续自动存记录，自动提炼仍先产生候选，由用户确认后用于后续写作。

## 修复结论

| 问题 | 根因/风险 | 现在的行为与证据 |
| --- | --- | --- |
| 收件箱→我的资料显示完全相同 | 原 `changeSection('library')` 只在当前库不是自有库时改 `kbId`；收件箱本来就是自有库 | 分区显式解析；我的资料只能选主题资料集，只有收件箱时显示创建引导；7 项数据规则 + 4 项真实组件行为测试 |
| 收件箱可以选择任意个人资料集 | 两个页面共用完整 `nativeBases` 下拉，分区与数据脱节 | 收件箱固定显示收件箱名称；个人与团队下拉各自过滤 |
| 刷新/直接链接丢失分区上下文 | URL 只保存 `kb`，没有保存空分区和项目筛选 | 保存 `section/kb/project`；旧 `?kb=` 继续推断正确分区；外部同路由切换也同步组件 |
| 切换或直接链接丢弃正在编辑的研究稿 | 同一路由查询更新与页面离开保护不完全一致 | 分区/项目切换及同路由导航在忙碌时阻止，在脏稿状态确认；取消则保留当前库与正文 |
| 只读成员仍看到创建入口 | 研究页绕过已有侧栏角色门禁 | 创建资料集、启用收件箱仅贡献者及以上可见；团队管理仅管理员及以上且部署支持组织时可见；贡献者共享资料权限保留 |
| 未解析完的所选资料仍可点击资料问答/写稿 | 只有共享按钮使用 `selectionReady` | 所选资料全部可检索前禁用问答/写稿；整库问答与已完成资料仍正常；列表保留解析状态与错误 |
| 无视觉模型时图片上传缺乏可用归档路径 | 原生图片识别要求 VLM，单纯上传不能证明已经识别正文 | 显式选择“识别图片内容 / 仅保存原图”，默认仍识别；无 VLM 时必须用户主动选择原图归档，才传 `process_config.image_archive_only:true`；混合批次只对图片生效。`archived` 显示“原图已归档 · 未识别”，不满足写作/问答选材条件；4 项回归 |
| 无 Embedding 的资料集被误判不能发布笔记 | 原页面强制要求摘要模型加 Embedding 或 Wiki，忽略关闭检索索引的合法资料库 | 与服务端 `NeedsEmbeddingModel()` 对齐：只有开启 vector/keyword 时缺 Embedding 才暂存笔记草稿；关闭索引仍可发布/解析并用于指定资料写作；完成状态显示“已整理”，不虚称“可检索”；3 项新回归 |
| 多项目共享同一库出现重复下拉项 | 分享按组织存储，选择值却是知识库 ID | 当前项目范围内按知识库 ID 去重，项目卡仍保留组织关系 |

实现：`frontend/src/views/research/workspaceNavigation.ts` 与 `ResearchWorkspace.vue`；没有重建知识库、移动或删除既有用户资料。

## 研究稿弹窗关闭可达性追加

浏览器验收发现版本记录的默认关闭图标未暴露为有名称的按钮。源码核对确认 TDesign 1.19.2 默认输出点击 `span`，没有按钮角色或可访问名称；其 Esc 处理仅判断 `KeyboardEvent.code`。本轮仅修改 `ResearchDraftEditor.vue` 的四个弹窗：引用来源、新建文稿、修改提案和版本记录，关闭槽使用带中文 `aria-label` 的按钮；显式使用正确的 `close-on-esc-keydown` 属性；增加仅在本组件弹窗打开时生效的 `key/code` 兼容回退，并在卸载时清理监听。忙碌操作不被误关闭，已由嵌套弹出层处理的 Esc 不再重复处理。

新增 5 项回归覆盖按钮可达性接线、无 code 的 Esc、四类关闭动作、忙碌/嵌套弹窗保护及无弹窗时不干预 Esc。研究模块 **52 项测试通过**，类型检查通过；本次没有修改全局弹窗或样式。更新后的静态清单为 223 个 Vue 文件、2563 个交互节点。
